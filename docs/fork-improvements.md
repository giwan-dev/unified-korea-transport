# 포크의 사용성 개선

원본: <https://github.com/radix24/unified-korea-transport>  
포크: <https://github.com/giwan-dev/unified-korea-transport>

이 포크는 원본의 도로·철도·공항·예산·사업·시뮬레이션 규칙을 유지합니다. 별도의 철도 전용 게임이나 자동 도로 생성 규칙을 포함하지 않습니다.

## 적용한 편의 기능

- 기본 지표를 ‘기본 배경 (남북 같은 색)’으로 시작합니다. 인구·소득 등의 지표 색칠은 범례에서 선택할 수 있습니다. 철도 건설을 시작할 때 자동으로 인구 지도로 바꾸지 않습니다.
- 지도 위 열차 위치 애니메이션과 관련 범례 설정을 제거했습니다. 운행 계통·노선도·수요 계산은 원본 기능입니다.
- 스크롤·트랙패드 줌 감도를 높였습니다. 원본 확대·축소 버튼의 한 단계 줌은 유지합니다.
- 지도를 이동하거나 확대·축소하면 현재 위치와 줌(방향·기울기 포함)을 브라우저에 저장하고 새로고침 후 복원합니다. 저장 데이터가 잘못되었거나 저장을 차단한 환경에서는 기본 화면으로 시작합니다.
- 고속도로의 테두리도 클릭·묶음 선택·건설 스냅 대상으로 처리합니다. 선을 직접 누르면 주변 철도보다 우선 선택합니다.
- 건설 중 역 표식·이름을 더 낮은 확대 수준부터 표시합니다. 지도에서 역을 누르거나 건설 패널에서 역 이름·노선을 검색해 경유지로 추가할 수 있습니다.
- 계획선 가까이를 클릭하면 두 경유지 사이에 삽입하는 원본 기능을 유지합니다. 기존 역을 선택한 경우에도 해당 역의 노드를 유지한 채 중간에 삽입합니다.
- 같은 종류의 운영 중 선로가 경유지 사이를 연결하면 실제 선형을 초록색으로 표시하고 공사·사업비에서 제외합니다. 나머지 구간만 신설합니다. 공사 중·폐선·가상 운행 계통·다른 종류의 선로는 재사용하지 않습니다.
- 전 구간을 재사용할 수 있으면 ‘전 구간 기존선 이용’으로 표시하고 새 사업을 만들지 않습니다. 직선화 등 별도의 원본 사업은 기존 동작을 유지합니다.

## 서울–행신의 구분

원본 OSM 데이터에서 서울–행신은 일반철도인 경의선으로 분류됩니다. KTX도 이용하는 구간이므로 고속철도 계획에서 기존선 공용 구간으로 재사용합니다. 일반철도 전체를 고속선으로 취급하거나 기존 속도를 높이지 않습니다. 실제 경로는 데이터의 경의선 연결을 따라 찾습니다.

확인 자료: [한국철도공사 시간표·노선도](https://info.korail.com/info/contents.do?key=857), [KTX 열차시간표](https://www.gwangju.go.kr/traffic/contentsView.do?pageId=traffic20).

## 원본에 이미 반영된 기능

원본의 강·호수 물 영역 표시, 경의선 도라산–판문 복원안, 동해선 군사분계선–감호 복원안을 유지합니다. 원본의 중간 경유지·선 위 스냅 기능을 확장하므로 자체 구현의 코드·데이터를 덧씌우지 않습니다.

## 실행·검증

```sh
python3 tools/serve.py 5173
# http://localhost:5173

npm install
npm test
npm run test:e2e
```

게임 실행은 Python 정적 서버만으로 충분합니다. npm 패키지는 개발 테스트용이며 브라우저 검증에는 설치된 Google Chrome을 사용합니다. 개발 서버는 병렬 모듈·지도 데이터 요청을 수용하도록 연결 대기열을 확장했습니다.
