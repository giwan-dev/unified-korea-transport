# UI 사용성 점검과 개선 (2026-10)

"메뉴를 찾기 어렵다"는 의견을 받아, 처음 하는 사람 입장에서 화면 구조를 점검하고 고친 기록이다.

## 1. 점검 결과 (고치기 전)

### 화면 구성
- **상단 바**: 연도·가용 예산·부채·지지율·남북 통합도 숫자, 소요 시간, 다음 해. 숫자는 눌러도 아무 일이 없었다.
- **오른쪽 패널 탭 6개**: 현황 · 건설 · 사업 · 민원 · 통계 · 설정. 탭 안 소제목은 접는 묶음.
- **지도 왼쪽 아래 범례**: 보기 메뉴(모두·도로만·철도만·항공만·아무것도 안 보기)와 지표 색칠. 범례 안에 있어 메뉴인 줄 알기 어렵다.
- **지도를 눌러 여는 선택 패널**: 구간(개량·노선 이름), 시군구(이름·지방자치), 공항(노선 개설·폐지), 역(노선도·운행 계통).

### 찾기 어려운 기능
| 기능 | 있던 곳 | 문제 |
|---|---|---|
| 광역시 승격, 북측 행정구역 복원, 북측 지방자치 도입, 북측 노선 이름 바꾸기 | 설정 › 지방자치·행정구역 | 게임 진행 이벤트인데 저장·새 게임과 같은 설정 탭 안, 그것도 접힌 채 |
| 국가 대형 사업 (한일해저터널·제주 연장·시베리아 횡단철도) | 설정 › 국가 대형 사업 | 건설 성격인데 설정 탭 |
| 이주 정책 | 설정 › 정책 | |
| 항공 노선 자동 운영 | 설정 › 항공 | 공항 패널(노선 개설)과 떨어져 있음 |
| 철도 회사 재원·배당·합병 | 통계 › 철도 운영사 | 조작 단추가 통계(읽기) 탭 안 |
| 노선 감편·폐선·재개통 | 통계 › 영업계수 · 노선 정리 | 같은 문제 |
| 운행 계통 표 / 짜기 | 통계 › 운행 계통 / 건설 › "역 골라 특급·급행 짜기" | 한 기능이 두 탭에 나뉨 |
| 옛 이름 되찾기 | 건설 맨 아래 | 지명 정책인데 건설 도구 사이 |
| 구간 개량 | 지도에서 구간 누르기만 | 패널 어디에도 입구가 없음 (첫 화면 안내 문장뿐) |
| 예산 내역 | 사업 탭 첫 줄 | 상단 바 숫자와 이어지지 않음 |

### 흩어진 기능
- **철도 운영**: 운행 계통(통계·건설·역 패널), 회사 수지(통계), 노선 정리(통계)
- **정책·이벤트**: 설정(지방자치·대형 사업·이주·항공), 건설(옛 이름), 민원(지자체 제안)
- **도움말**: 없음. 단축키(Shift+드래그, Enter·Esc·Backspace)는 건설 탭 안내 문장에만 있음

## 2. 고친 것

### 탭 재배치 (6 → 7)
| 탭 | 담는 것 |
|---|---|
| 현황 | 올해 성적, 지지율 까닭, 인구·소득, 교통, 기록 |
| 건설 | 새 노선 도구, 계획 사업 (분류별) |
| 사업 | 진행 중인 공사, 예산 투입 속도, 민자사업, 완공 |
| **운영** (새로) | 철도 운행 계통(짜기 단추 + 표), 철도 회사 재원·합병, 영업계수·감편·폐선, 항공 자동 운영 |
| **민원·정책** | 지자체 SOC 제안, 확장 요구, 이주 정책, 지방자치·행정구역 이벤트, 국가 대형 사업, 옛 이름 되찾기 |
| 통계 | 항공·관광·철도·도로 순위와 추이 (읽기 전용) |
| 설정 | 도움말, 저장 슬롯, 새 게임, 데이터 출처 |

원칙: **읽기(통계)와 조작(운영·민원·정책)을 나누고, 게임 진행 중에 고르는 정책·이벤트는 한 탭에** 모았다. 설정은 게임 밖의 일(저장·새 게임)만.

### 한두 번 클릭으로
- **다음 해**: 상단 바 오른쪽 (그대로)
- **예산**: 상단 바 가용 예산·부채를 누르면 사업 탭(투입 속도), 지지율·통합도를 누르면 현황 탭
- **건설·개량·운행**: 메뉴 찾기에서 "새로 놓기: 고속도로…", "구간 개량하기", "역 골라 특급·급행 짜기"를 바로 실행
- **사업 위치**: 사업 탭에서 사업 이름을 누르면 지도에서 찾아감 (앞서 넣음)

### 메뉴 찾기 (Ctrl+K, /, 상단 바 단추)
- 이름 일부, 띄어 쓴 여러 낱말, 초성(예: ㄱㅅㄷㄹ → 고속도로)으로 찾는다
- 찾는 대상: 탭과 모든 접는 묶음 제목(화면에서 자동으로), 건설 도구, 계획 사업, 시군구, 철도 노선, 보기 메뉴·지표, 깊은 항목 바로가기(광역시 승격·북측 복원·행정구역 정리·대형 사업 이름·폐선·회사 합병·저장 등)
- 바로가기는 탭을 열고 묶음을 펼친 뒤 그 항목을 노란 테두리로 잠깐 밝힌다

### 처음 안내
- 처음 한 번 6단계: 지도(구간 누르기·Shift+드래그) → 오른쪽 패널 탭 → 예산과 지지율 → 보기 메뉴 → 메뉴 찾기 → 다음 해
- 상단 바 "?", 설정 › 도움말, 메뉴 찾기의 "처음 안내 다시 보기"로 다시 연다
- 좁은 화면에서는 안내 카드가 화면 아래쪽에 붙는다

### 선택 패널 단추 배치 통일
- 동작 줄(`.actions`): 주 동작이 먼저, 취소·운행 중단은 오른쪽 끝. 좁은 화면에서 최종 동작(착공·운행 시작 등)은 손가락 크기(높이 40px)로 늘어난다
- 이름 + 단추 항목(`.item.opt`): 이름은 왼쪽, 단추 묶음은 오른쪽, 좁으면 단추가 아래 줄 오른쪽으로 (개량 목록, 항공 노선, 운행 계통, 폐선 노선, 계획 사업)
- 따로 떠 있던 단추(노선도·직선화·새 계통·구간 선택)를 동작 줄로 묶음, 이름 바꾸기 단추는 모두 "바꾸기"
- 검사: 데스크톱·375px에서 구간(도로·철도·도시철도)·시군구·공항·역·운행 계통 편집·역 골라 짜기·직선화 패널과 각 탭의 모든 단추가 겹치거나 6px보다 붙거나 패널 밖으로 나가지 않음

### 처음 안내 끄기
- 안내 카드의 "다시 보지 않기", 설정 › 도움말의 "게임을 열 때 처음 안내": 처음 한 번만(기본) / 새 게임을 시작할 때마다 / 보지 않기

## 3. 남은 과제 (이번에 하지 않음)
- 보기 메뉴를 범례 밖(지도 위 단추 묶음)으로 꺼내기: 범례와 함께 쓰는 공간이 좁아 이번에는 두었다
- 지방자치·국가 대형 사업 항목 안의 단추(광역시 승격 도시 단추 등)는 원본 세션이 같은 함수를 고치는 중이라 손대지 않았다
- 375px에서 상단 바 숫자는 연도·예산만 보이고 나머지는 옆으로 밀어 본다 (누르면 탭으로 가는 기능은 같다)
