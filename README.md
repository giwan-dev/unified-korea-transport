# 통일 한반도 교통망

**플레이: https://radix24.github.io/unified-korea-transport/**

남북이 오늘 통일되었다고 가정하고, 한정된 SOC 예산으로 고속도로·고속철도·도시철도·공항·해저터널을 놓거나 기존 재래선·국도를 개량하는 웹 게임입니다.

- 교통수요는 중력모형과 로짓 수단선택(승용차·지역 간 철도·대중교통·항공)으로 추정하고, 혼잡을 반영해 배정합니다.
- 교통망이 바뀌면 접근성과 소득이 달라집니다. 이에 따라 시군구 사이와 읍면동 사이로 인구가 이동하고, 지역별 인간개발지수(HDI)와 주민 행복도가 변합니다.
- 중국 동북·러시아 연해주·일본의 주요 도시와 국경 통과점, 여객선 항로, 국제선 항공으로 이어집니다.
- 북측에서 지도자 이름이나 선전 구호로 바뀐 지명을 예산을 들여 옛 이름으로 되찾을 수 있습니다.

## 실행

빌드 과정이 없는 정적 웹페이지입니다. 저장소 루트에서 정적 서버를 띄우면 됩니다(`python -m http.server`도 되지만, 개발 중에는 캐시를 끄는 `tools/serve.py`가 편합니다).

```bash
python tools/serve.py 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. GitHub Pages에 그대로 올려도 동작합니다.

## 플레이

- **개량**: 지도에서 도로·철도 구간을 누르면 개량할 수 있습니다. 같은 이름 노선 전체를 한 번에 고를 수도 있습니다.
  - 도로: 차로 확장, 고속도로 격상
  - 철도: 직선화(곡선 구간 펴기), 복선화, 전철화(북의 직류 3kV → 교류 25kV), 고속화
  - 도시철도: 급행화, 열차 증편
  - Shift를 누른 채 지도를 끌면 여러 구간을 한꺼번에 골라 개량할 수 있습니다.
  - 구간 패널의 "구간 선택"을 누르고 역(도로는 IC·교차점) 두 곳을 차례로 누르면 그 사이 경로만 골라집니다. 그 구간만 개량하거나, 철도는 바로 직선화할 수 있습니다.
- **신설**: 건설 탭에서 종류를 고르고 지도를 차례로 누릅니다.
  - 종류: 고속도로·국도·고속철도·일반철도·도시철도·해저터널
  - 노선은 찍은 점을 지나는 부드러운 곡선으로 놓입니다.
  - 노드 붙이기를 켜면 기존 역·IC에 이어지고, 선 위 붙이기를 켜면 기존 노선 중간에 새 IC·역을 만듭니다. 정확히 누르지 않아도 가까우면 붙고, 도로 끝점이 도로에 닿지 않으면 착공할 때 가장 가까운 도로(5km 안)에 저절로 이어집니다.
  - 중국·러시아 땅으로 이어 국경 너머 도시와 연결할 수 있습니다(외국 구간은 공사비 절반 부담).
  - 기존 노선의 종점에서 이어 그리면 기존선 연장으로 보고 그 노선 이름을 이어 씁니다(끌 수 있음). 아니면 신설 노선입니다.
  - 고속도로는 약 40km마다 휴게소가 저절로 생기고, 설치비가 사업비에 들어갑니다.
  - 노선 이름은 경의·경원·경부처럼 전통 축 이름을 따서 자동으로 붙고(예: 경의고속철도), 바꿀 수 있습니다. 새 역·IC·JCT 이름도 마찬가지입니다.
- **진행 중인 사업**: OSM에 공사 중으로 등록된 도로·철도(GTX, 도시철도, 고속도로 등)는 처음부터 "진행 중인 사업"으로 들어옵니다.
  - 남은 사업비(절반은 이미 확보된 계속비로 봄)를 해마다 예산에서 내고, 다 지어야 개통합니다.
  - 사업 탭에서 사업마다 투입 속도(50~200%)를 바꾸면 연 투입액과 완공 연도가 달라집니다. 빠르게 하면 남은 사업비에 할증이 붙습니다.
- **계획 사업**: 건설 탭에 국가·광역 교통계획의 노선(GTX-C·D·E, 위례신사선, 월곶판교선, 강북횡단선, 충청권 광역철도, 달빛철도, 남부내륙철도, 경의고속철도 등, `data/plans.json`)이 있습니다. 누르면 경유지가 찍힌 채로 그리기가 열리고, 확인하고 고친 뒤 착공합니다.
- **공항·항공**: 공항을 누르면 확장할 수 있고, 건설 탭에서 새 공항을 놓을 수 있습니다.
  - 항공 노선은 수요에 따라 자동으로 증편·신규 취항·단항됩니다(설정에서 끌 수 있음).
  - 공항 패널에서 노선을 직접 개설하거나 운항을 중단할 수 있습니다.
- **운행 계통**: 시티즈: 스카이라인의 철도 노선처럼 짭니다. 철도 구간을 누르고 "새 운행 계통 짜기"를 고릅니다.
  - 정차역(모든 역·큰 역 절반·주요 역만 단추로 시작), 등급(특급·급행·보통: 정차 방식과 요금), 열차 종류, 편성 수만 정하면 됩니다.
  - 열차 종류: 고속열차(300km/h급), 준고속 전동차(250), 간선 전동차(180), 광역 통근 전동차(110, 정원이 큼), 디젤 객차(120, 비전철 구간 가능). 전동차는 비전철 구간을 지나는 노선에 넣을 수 없습니다.
  - 하루 운행 횟수는 편성 수로 저절로 정해집니다(24시간 동안 편도를 되풀이). 편성을 늘리면 배차 간격이 짧아지고, 차량비가 듭니다.
  - 특급·급행 기본 정차역은 승하차와 역세권 인구가 큰 역을 노선 길이에 맞춰 고릅니다(경부선 특급이면 서울·대전·동대구·부산 등).
  - 통과역마다 정차 시간이 줄고, 정차역은 배차 간격만큼 기다림이 짧아집니다. 열차는 같은 선로 용량을 나눠 씁니다.
  - 모든 노선에는 보통(고속선은 고속) 열차가 이용객만큼 저절로 다닙니다.
- **구간 직선화**: 철도 구간 패널의 "구간 직선화 (두 역 고르기)"를 누르고 같은 노선의 두 역을 누르면, 그 사이를 가장 단순한 곡선(직선이나 한 번 휜 곡선)으로 새로 놓는 안이 나옵니다.
  - 길이·최고 속도(곡선 반경 기준)·주행 시간 변화와 사업비를 보고 착공합니다.
  - 완공되면 옛 구간은 폐선하고, 사이의 역은 새 선로 위 가장 가까운 자리로 옮깁니다(역 이름과 운행 계통 정차역은 그대로 이어지고, 너무 가까워진 역은 합칩니다).
- **역 패널**: 지도나 노선도에서 역을 누르면 지나는 노선과 노선별 통과 인원, 지역 간 승하차, 역세권 인구(반경 1·3km), 서는 계통과 통과하는 계통(배차 간격), 같은 역·도보 400m 안의 환승 노선이 나옵니다.
- **노선도**: 철도·도시철도 구간 패널의 "노선도 보기"를 누르면 노선을 직선으로 편 그림이 지도 아래에 뜹니다.
  - 역 순서와 구간별 혼잡도(V/C 색), 운행 계통별 정차역(●)과 통과역(│), 계통 열차의 혼잡도를 보여 줍니다.
  - 열차는 24시간 다닙니다. 시계를 따라 계통별 열차(▶ 하행, ◀ 상행)가 시간표대로 움직이며, 재생 속도를 바꾸거나 멈출 수 있습니다.
  - 모든 노선에는 모든 역에 서는 보통 열차(고속선은 고속 열차)가 이용객만큼 저절로 다닙니다.
- **철도 운영사**: 남측 철도는 코레일(KORAIL), 북측 철도는 KPRail이 맡습니다(배지는 게임에서 만든 것).
  - 통계 탭에서 회사별 연 수입·비용·영업이익·영업계수·잔액을 봅니다. 북측 운임은 남북 통합도만큼 오릅니다.
  - 해마다 영업이익이 잔액에 쌓이고, 재원을 "운영사 자체 재원"으로 고르면 그 잔액으로 자기 노선을 개량·신설하거나 차량을 삽니다.
  - 적자나 사업비 부족분은 정부가 SOC 예산에서 메워 잔액은 0 밑으로 내려가지 않습니다. 배당(잔액 → 정부)과 출자(정부 → 회사)도 할 수 있습니다.
  - 남북 통합도 40% 이상이면 두 회사를 합병해 이름을 정할 수 있습니다(운영비 5% 절감).
- **운행 다이어**: 노선도에서 "운행 다이어 (24시간)"를 누르면 가로 0~24시, 세로 역으로 모든 열차의 운행선을 봅니다(보기 전용).
- **수익성**: 통계 탭과 노선 패널에서 노선·운행 계통·항공 노선의 연 수입, 비용, 영업계수(비용 ÷ 수입 × 100)를 봅니다.
- **재정사업·민자사업**: 신설 노선을 그릴 때 사업 방식을 재정(정부 예산), 민자 BTO(통행료·운임으로 회수), 민자 BTL(정부가 임대료 지급) 중에서 고릅니다.
  - 민자 조건: 운영 기간(20·30·40년), 민간 목표 수익률, 통행료·운임 수준(BTO, 재정 대비 배수), 최소운영수입보장(BTO), 정부 건설보조금 비율.
  - "수요 예측·민간 수익성 검토"를 누르면 통행료를 붙인 채로 다 지었다고 치고 이용을 예측해 첫해 수입, 운영비, 민간 수익률(IRR)을 보여 줍니다. 목표 수익률에 못 미치면 민간이 참여하지 않아 착공할 수 없습니다.
  - 민자로 지으면 정부는 건설보조금만 냅니다. 통행료·추가 운임은 실제로 이용을 줄입니다. 해마다 실제 이용으로 정산해, 예측보다 수요가 적으면 최소운영수입보장을 정부가 메우고(개통 초기는 기준을 낮춤), BTL은 임대료를 냅니다. 운영 기간이 끝나면 정부로 귀속됩니다. 사업 탭에서 예측 대비 실적과 정부 지급 누계를 봅니다.
- **효과 미리보기**: 신설 노선 그리기·계획 사업·구간 직선화·개량 패널의 "효과 미리보기"를 누르면, 다 지었다고 치고 한 해 통행배정을 지금 그대로와 견줘 보여 줍니다(약 40초): 새 구간 이용, 도로 차량 통행 시간, 철도 이용, 유발 수요, 정체 도로 길이, 혼잡이 줄어드는 곳.
- **저장 슬롯**: 설정 탭에서 진행을 세 개까지 따로 저장했다가 불러올 수 있습니다.
- **소요 시간**: 위쪽 ⏱ 단추를 누르고 두 지점을 찍으면 승용차·철도·버스·항공의 소요 시간과 경로를 보여 줍니다(그해 혼잡 반영).
- **관광**: 주요 관광지(`data/tourism.json`)가 국내 관광 통행과 국외 입국 관광 수요를 끌어옵니다. 북측 관광지는 남북 통합도만큼 열립니다.
- **통계**: 항공 노선·공항, 철도역, 혼잡 구간 순위와 연도별 추이를 봅니다.
- **지명**: 지역을 누르면 이름을 바꿀 수 있습니다(무료, 표시만 바뀜). 건설 탭의 "옛 이름 되찾기"는 예산이 들고, 완공되면 주민 행복도가 오릅니다.
- **다음 해**: 공사가 진행되고 통행·인구·HDI·행복도가 갱신됩니다.
- **민원**: 혼잡도(V/C)가 1을 넘은 노선이 V/C 높은 순으로 확장 요구에 올라옵니다.
- **지방자치·선거**: 남측은 처음부터 지방자치가 시행 중이고, 2030년부터 4년마다 광역·기초단체장 선거(더불어민주당 대 국민의힘)가 열립니다.
  - 당선된 단체장은 해마다 자기 지역의 혼잡 구간 개량을 중앙정부에 제안합니다(민원 탭). 받아들이면 그 단체장의 지지율이 오르고, 완공되면 더 오릅니다. 거절하거나 2년 동안 답하지 않으면 내려갑니다.
  - 득표는 지역 기본 성향(2022년 지방선거를 단순화한 가정값, 북측은 반반)에 단체장 지지율과 완공 실적을 더해 정합니다. 두 정당에 같은 규칙을 씁니다.
  - 설정 탭 이벤트: 북측 지방자치 도입(통합도 30% 이상), 북측 행정구역 1945년 이전 복원(강원은 강원북도·강원남도로), 북측 옛 직할시(평양·남포) 독립(복원 뒤), 남측 인구 100만 이상 시의 광역시 승격.
  - 범례에서 정당 지도(시군구청장·광역단체장)를 고를 수 있습니다.
- **정책**: 설정 탭에서 북→남 이주 정책(자유·제한·통제)을 정합니다.

## 데이터 다시 만들기

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r pipeline/requirements.txt
bash pipeline/download.sh
.venv/Scripts/python -X utf8 pipeline/build_admin.py     # 행정구역 기준 도형 (남 행정동, 북 보로노이)
.venv/Scripts/python -X utf8 pipeline/build_basemap.py   # 자체 배경지도
.venv/Scripts/python -X utf8 pipeline/build_data.py      # 존·도로·철도·도시철도망
.venv/Scripts/python -X utf8 pipeline/build_grid.py      # 인구 격자·소구역·데이터 버전
.venv/Scripts/python -X utf8 pipeline/build_names.py     # 옛 이름 되찾기 대상
.venv/Scripts/python -X utf8 pipeline/build_roads.py     # 확대 시 보이는 OSM 도로 배경 (도별 파일)
.venv/Scripts/python -X utf8 pipeline/build_water.py     # 큰 강·호수의 물 면 (한강·낙동강·대동강 등)
```

(macOS·Linux에서는 `.venv/bin/python`)

데이터를 다시 만들면 기준 연도 결과도 다시 계산해야 시작이 빠릅니다. `python tools/serve.py 8000`으로 띄운 뒤 `http://localhost:8000/tools/baseline.html`을 열면 `data/baseline.*`이 저장됩니다. 데이터 버전(`data/meta.json`)이 맞지 않으면 게임이 시작할 때 직접 계산합니다(수 분).

## 구조

```
index.html, css/        화면 (처음 불러오기 화면 포함)
js/main.js              게임 진행·패널
js/ui/map.js            지도 (자체 벡터 배경지도, MapLibre GL)
js/data/netpack.js      이진 네트워크 읽기
js/sim/                 시뮬레이션 (웹 워커에서 실행)
  graph.js              최단경로
  model.js              수요·배정·항공·경제·HDI·인구이동
  params.js             모델 파라미터
js/game/                예산·사업·민원·이름 짓기·곡선·국외 연결
pipeline/               공개 데이터 → data/
tools/                  개발 서버, 기준 연도 사전 계산
docs/model.md           모델과 가정값 설명
```

## 데이터 출처와 라이선스

- 남측 행정동 경계: 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것입니다.
  - 가공: [vuski/admdongkor](https://github.com/vuski/admdongkor), CC BY 4.0
  - `data/admin/`의 남측 경계도 같은 조건을 따릅니다.
- 도로·철도·도시철도·북측 행정구역·지명: © [OpenStreetMap](https://www.openstreetmap.org/copyright) 기여자, ODbL 1.0.
  - `data/`의 파생 데이터도 ODbL을 따릅니다.
- 인구 격자: [WorldPop](https://www.worldpop.org/) 2025 (R2025A) 1km constrained UN-adjusted, CC BY 4.0
- 배경지도의 주변국 육지·하천 중심선·호수·도시: [Natural Earth](https://www.naturalearthdata.com/) (공공 영역). 강·호수의 물 면은 OpenStreetMap
- 라벨 글꼴의 숫자·영문 글리프: [OpenFreeMap](https://openfreemap.org/) 글꼴 서버 (한글은 브라우저 글꼴)
- 공항·항구·국외 도시 좌표와 용량, 옛 지명 대조표, 관광지 방문객 수(`data/air_sea.json`, `data/historic_names.json`, `data/tourism.json`)는 공개 자료를 바탕으로 직접 정리한 값이며 확인이 필요합니다.

소득·HDI 초기값과 공사비 단가는 게임용 가정값입니다. 근거와 한계는 [docs/model.md](docs/model.md)에 정리했습니다.
